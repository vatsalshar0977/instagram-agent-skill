## THE SUFFIX SYSTEM (most reliable way to win)

Instagram usernames allow letters, numbers, **periods** and **underscores** (30 chars max). A dot reads cleaner than an underscore and is far less likely to be taken than the bare word.

Take any base you liked and add:

| Suffix | Example | Vibe |
|---|---|---|
| `.photo` | `@pankhi.photo` | clean, professional |
| `.photos` | `@kalrav.photos` | slightly warmer |
| `.studio` | `@halcyon.studio` | art practice |
| `.works` | `@theflyway.works` | portfolio, gallery |
| `.in` | `@pankhi.in` | **India + it's a URL ending — reads deliberate** |
| `.birds` | `@halcyon.birds` | explicit niche |
| `.frames` | `@ardea.frames` | print-ready |
| `.gallery` | `@aves.gallery` | selling intent |
| `.wild` | `@pankhi.wild` | field, not studio |
| `.art` | `@vatsal.sharma.art` | artist, not hobbyist |

## RULES THAT STILL HOLD

- **No digits, no trailing underscores.** `@pankhi_07` kills a gallery grid.
- **Dots beat underscores.** `@pankhi.photo` > `@pankhi_photo`.
- **No gear in the handle.** No `@r8`, no `@canon`.
- **Keep the name field fixed** at `Vatsal | Bird Photography` (25/30) — that's what search reads, so the handle only has to be memorable.
- **Don't overthink it.** Handles are changeable. Nine frames you'd print are not.
