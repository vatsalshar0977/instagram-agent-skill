# PRE-LAUNCH PLAN — Portfolio Bird Account, Canon R8

**Rule for the next 30 days: do not post.** You are new to birds. Your first frames will be reference shots. Nobody sees them. You launch once, with nine frames worth printing.

It is late September. Migration builds through October and peaks November–February. Time this right and your launch lands with the season.

---

## WEEK 1 — Learn the birds, not the camera
**Outings:** 3 (dawn, 6:00–9:00) · **Patch:** pick ONE. Indroda Nature Park, or a lake edge near you.

- [ ] Set the R8 baseline: Manual + Auto ISO (max 6400) · 1/1000 perched · widest aperture · Servo AF · Subject detect Animals · Eye detect ON · Spot AF · 20 fps · RAW
- [ ] Set up **RAW burst mode with 0.5s pre-capture** and test it on something that moves (leave, dog, anything). Learn the muscle memory before a bird needs it.
- [ ] Install Merlin (ID) and eBird (what's being seen near you). Create an eBird account.
- [ ] Start the **Species Log**: date · place · species · frames · keepers · light · what you learned
- [ ] Shoot only perched birds. Fill the frame. Get to eye level. No chasing.

**End of week check:** can you name 10 species from your own frames without looking them up?

## WEEK 2 — Prediction
**Outings:** 3, same patch, one of them an evening (4:30–sunset).

- [ ] Watch one perch for 30 minutes without shooting. Learn when the bird returns to it.
- [ ] Practice pre-flight signals: thin neck, head-bob, alert posture, weight shift, look up. Anticipate the takeoff instead of reacting to it.
- [ ] Try back-button AF (AF-ON = tracking, `*` = single point) — decide if it's yours or not.
- [ ] Test 20 fps vs 40 fps on the same species. Look for rolling-shutter skew in the wings at 100%.

**End of week check:** did you get one frame where you pressed *before* the bird moved?

## WEEK 3 — Build the archive
**Outings:** 4. Add one new location (Thol if the season allows, or a second patch).

- [ ] Shoot for light, not for species. First 90 minutes after sunrise only.
- [ ] Start rating: sharp → keeper → **portfolio**. Be ruthless.
- [ ] Build your edit: one preset, applied once, then adjust per frame. Lock the look now, not after launch.
- [ ] Cull on a calibrated screen at 100%. If the eye isn't sharp, it's a record shot.

**End of week check:** how many frames pass the *would I print this at 12×18* test?

## WEEK 4 — Edit and stage
**Outings:** 2–3, filling gaps only (a species you're missing, better light on a frame you like).

- [ ] Select the **launch 9** — not nine species, nine *frames*. Cohesive mood, one look.
- [ ] Export 4:5 portrait for feed, 9:16 for Reels covers. No watermarks, no borders.
- [ ] Set up the account: name field, bio, one print link (Section 10 of the playbook).
- [ ] Shoot the **Format C** B-roll: hide going up in the dark, breath, empty branch, sun arriving. Bank it.
- [ ] Draft the first 5 captions. Short, atmospheric, species + place + time.
- [ ] Build the `Prints` highlight skeleton (price list can come post-launch).
